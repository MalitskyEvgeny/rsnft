# Моделирование теплового режима осадочного бассейна

Решение двух задач:

- **Прямая задача** — 2-D численная модель эволюции температуры осадочного
  бассейна (метод конечных объёмов, Julia): по данным о геометрии, литологии
  и тепловом потоке на границе считается температурное поле T(x, z) на
  геологической шкале времени.
- **Обратная задача** — восстановление неизвестного глубинного теплового потока
  q(x, t) по скважинным наблюдениям: температурные профили и отражательная
  способность витринита (%Ro). Минимизация функционала невязок (дифференциальная
  эволюция + полировка Нелдера–Мида) на адаптивной сетке.

## Требования

- [Julia](https://julialang.org/downloads/) 1.9+ (проверено на 1.10+).
  Проверить: `julia --version`.
- Пакеты устанавливаются один раз из папки `rsnft3`:

```bash
cd rsnft3
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

## Данные

Скрипты по умолчанию ищут данные в папках рядом с `rsnft3` (на уровень выше):

```
<родительская папка rsnft3>/
├── rsnft3/                        # эта папка
├── Данные_для_прямой_задачи/      # вариант data1 (используется по умолчанию) и data2
└── Данные для обратной задачи/    # TemperatureWellData.xlsx, VitriniteWellData.xlsx, ...
```

Если папки лежат иначе — передайте их флагами, ничего перемещать не нужно:
`-DataDir/--data-dir` (данные прямой задачи), `-InvDataDir/--inv-data-dir`
(скважинные данные), `-Wells/--wells` (список XLSX-скважин через `;`).

## Запуск

Все команды — из корня папки, в которой лежит `rsnft3` (родительской).
Сетка во всех прогонах — **адаптивная**: базовая 16×32 (nx×nz), максимальный
уровень измельчения 2 (равномерный солвер доступен флагом `-Uniform/--uniform`).

**Прямая задача** (адаптивный прогон солвера + отчёт):

```powershell
.\rsnft3\scripts\run_forward.ps1          # Windows (PowerShell)
```
```bash
./rsnft3/scripts/run_forward.sh           # Linux / macOS
```

**Обратная задача** (адаптивная сетка + отчёт + сводка приёмки в консоли):

```powershell
.\rsnft3\scripts\run_adaptive.ps1         # Windows (PowerShell)
```
```bash
./rsnft3/scripts/run_adaptive.sh          # Linux / macOS
```

**Обе задачи одной командой** (прямой прогон + инверсия + единый отчёт):

```powershell
.\rsnft3\scripts\run_full.ps1             # Windows (PowerShell)
```
```bash
./rsnft3/scripts/run_full.sh              # Linux / macOS
```

Каждый скрипт без флагов использует настройки по умолчанию (указанную сетку
и папки данных). Основные флаги (PowerShell ↔ bash): `-Out/--out` или `-OutDir/--out-dir`
(свой каталог результатов), `-OpenReport/--open` (открыть отчёт в браузере),
`-Grid/--grid`, `-DeBudget/--de-budget` (бюджет оптимизации).
Полный список — `rsnft3/scripts/README.md`.

Если PowerShell запрещает скрипты:

```powershell
powershell -ExecutionPolicy Bypass -File .\rsnft3\scripts\run_full.ps1
```

## Отчёт и как его читать

После прогона появляется каталог в `results/` рядом с `rsnft3` — точный путь
печатается в консоль в конце прогона. В нём — самодостаточный файл
**`report.html`**: интерактивный отчёт с графиками, открывается двойным щелчком
в любом браузере, интернет не нужен (Plotly встроен в файл).

- **Секция «Прямая задача»**: сводка прогона (сетка, число шагов, время, min/max T);
  температурное поле T(x, z) со слайдером по эпохам; термические профили в колонках;
  геометрия бассейна, литология, пористость.
- **Секция «Обратная задача»**: главный результат — блок **«Приёмка (условие 18)»**.
  Критерии прохождения: RMSE по температуре ≤ 2σ_T (при σ_T = 2 °C это 4 °C),
  RMSE по %Ro ≤ 0.10, не менее 95% температурных точек в пределах 2σ. Если
  критерии выполнены — восстановленный поток q(x, t) считается приемлемым.
  Далее: heatmap q(x, t) с таблицей значений по эпохам и x-узлам; профили T и %Ro
  по скважинам (модель против наблюдений с коридором ±σ); разброс ансамбля решений;
  картинка адаптивной сетки (`mesh_adaptive.png` рядом с отчётом).

Ориентир по времени: прямой прогон — минуты; обратная задача зависит от бюджета
оптимизации (от десятков минут до нескольких часов при полном ансамбле).
