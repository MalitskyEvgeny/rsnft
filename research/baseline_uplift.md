## Команда воспроизведения базлайна (полная, seed = 1)
```bash
cd rsnft3
julia --project=. run_inverse.jl --data-dir "../Данные для обратной задачи" \
  --wells "../Данные для обратной задачи/TemperatureWellData.xlsx;../Данные для обратной задачи/VitriniteWellData.xlsx" \
  --grid 20,40 --de-budget 100 --nm-iterations 20 --ensemble 1 --workers 2 --seed 1 \
  --out ../results/smoke_baseline_repro
```
Ожидание: J ≈ 24389.6, elapsed ≈ 195 с (при неизменённом objective.jl относительно коммита 42c11df).
